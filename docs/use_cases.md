# Use Cases - UAAventon

**System Actors:**
1. **Passenger:** Student searching for a ride to their destination.
2. **Driver:** Student offering available seats in their vehicle.

**Use Case List:**
- **UC01 - Authentication:** Log in using a `@edu.uaa.mx` email address.
- **UC02 - Vehicle Management (Driver):** Register, update, or remove a car.
- **UC03 - Publish Trip (Driver):** Create a route specifying origin, destination, available seats, and fare.
- **UC04 - Search Trip (Passenger):** Filter available trips by destination or date.
- **UC05 - Request Seat (Passenger):** Join a published trip.
- **UC06 - Manage Requests (Driver):** Accept or decline passenger join requests for a trip.
- **UC07 - Cancellation:** Cancel a trip (Driver) or leave a booked seat (Passenger).
- **UC08 - Rate:** Assign a 1 to 5-star rating upon trip completion.
